# Trabajo 1 - Bases de Datos: Sistema de Gestión

Este repositorio contiene la resolución de los ejercicios prácticos utilizando Programación Orientada a Objetos en C# (.NET Framework) y persistencia de información mediante archivos.

## Instrucciones para compilar y ejecutar

La solución contiene varios proyectos de consola separados (uno por cada ejercicio). Para probar un ejercicio específico, debes configurarlo como el proyecto principal antes de ejecutar:

1. Clonar el repositorio en el equipo local: `git clone https://github.com/davidpp19/Huera_Estacio_Montesdeoca_Andrade_Pena-Tr1`
2. Abrir el archivo de la solución (`.sln`) en **Visual Studio Community 2026**.
3. En el **Explorador de soluciones** (panel derecho), haz clic derecho sobre el proyecto que deseas evaluar (por ejemplo, `Ejercicio4`).
4. Selecciona la opción **"Establecer como proyecto de inicio"** (Set as Startup Project). Verás que el nombre del proyecto seleccionado se pone en negrita.
5. Presiona la tecla `F5` o haz clic en el botón verde de **"Iniciar"** (Play) en la barra superior.

**Nota sobre los datos de prueba:** Para el Ejercicio 4 (Cafetería), los archivos `.json` con los datos base consistentes entre sí están configurados en Visual Studio para copiarse automáticamente al directorio de ejecución (`bin/Debug`) al momento de compilar. No se requiere configuración manual de rutas.
